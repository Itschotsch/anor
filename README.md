# Anor

Published files of the Anor trading card game, served by GitHub Pages at https://itschotsch.github.io/anor/.

| Folder | What it is |
| --- | --- |
| `tcg-arena/` | The TCG Arena configuration (`main.json` and variants), card lists (`card-list-<label>.json`), starter decks and assets |
| `export/<label>/jpg/` | Card images, by edition label: `public`, `dev` (playtest), `Release1-StarterDecks`, `alt-art`, `hero` |

TCG Arena (through https://anor.cards/tcg-arena/) and the website load these URLs, so paths here do not change.

The cards, rules, templates and artworks live in a private repository; the balancing platform renders the card images and writes them here.
